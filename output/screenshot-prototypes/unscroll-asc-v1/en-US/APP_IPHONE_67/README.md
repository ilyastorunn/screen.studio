# Unscroll en-US iPhone screenshot set

This directory contains the ordered App Store Connect upload set.

- Slot: iPhone 6.9-inch accepted portrait size
- Dimensions: `1290 × 2796` pixels
- Format: opaque PNG, sRGB, three channels, no alpha
- Locale: `en-US`
- Upload count: seven screenshots

Upload the numbered PNG files in order. `qa-contact-sheet.png`, `README.md`, and `upload-order.json` are QA/support files and must not be uploaded as screenshots.

The size and no-alpha requirements were checked against Apple's current [Screenshot specifications](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications/) on 2026-09-04.
